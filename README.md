# Small Realms (Arbeitstitel)

Rundenbasierte Pixel-Strategie für Android und iOS – Advance-Wars-Loop, Einheiten als Daten, Karten aus dem Generator. Kostenlos, ohne Werbung. Zweites Spiel des Portfolios neben [Rune Rush](https://github.com/maestroDev3/game), gebaut mit Flutter + Flame von einem Menschen und einem KI-Agenten (Claude Code).

> Kleine Reiche, kurze Kriege. Speer schlägt Reiter, Reiter schlägt Bogen, und das Dorf in der Mitte entscheidet. Jede Karte ist neu, eine Partie dauert eine Mittagspause, ein Zug passt an die Haltestelle.
